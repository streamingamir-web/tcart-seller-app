ساخت APK با گیت‌هاب (بدون اندروید استودیو)
============================================

خلاصه: کد را در گیت‌هاب می‌گذاری. خود گیت‌هاب روی سرورش apk می‌سازد.
تو فقط فایل را دانلود و روی گوشی نصب می‌کنی.

قدم ۱ — حساب
اگر حساب نداری: https://github.com/signup
وارد حساب شو.

قدم ۲ — ریپوی خالی بساز
برو: https://github.com/new
- Repository name: tcart-seller-app
- Public بگذار (برای شروع ساده‌تر است)
- هیچکدام از گزینه‌های README / .gitignore / license را تیک نزن
- Create repository را بزن

قدم ۳ — فایل‌ها را آپلود کن
روی صفحهٔ ریپوی خالی، «uploading an existing file» را بزن.
کل محتویات پوشهٔ seller-app را بکش و رها کن داخل صفحه:
  C:\Users\R.GH-SYS\Desktop\tcart - Copy (5)\seller-app

مهم:
- خود پوشهٔ seller-app را نفرست؛ محتویات داخلش را بفرست
  (یعنی باید app و gradle و .github و gradlew و ... دیده شوند)
- فایل local.properties را اگر آمد حذفش کن / آپلود نکن
- بعد پایین صفحه Commit changes را بزن

قدم ۴ — صبر برای ساخت
بالای صفحه تب Actions را باز کن.
یک کار به اسم Build TCart Seller APK باید زرد/در حال اجرا باشد.
چند دقیقه صبر کن تا سبز شود.

قدم ۵ — دانلود apk
روی همان کار سبز کلیک کن.
پایین صفحه بخش Artifacts → tcart-seller-apk را دانلود کن.
زیپ را باز کن؛ داخلش فایل .apk است.
آن را به گوشی ببر و نصب کن.

اگر Actions سبز نشد، اسکرین خطا را بفرست.
